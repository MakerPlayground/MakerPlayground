# ALLI/O IDE Supplementary Material

This repository contains supplementary material for the paper titled "ALLI/O IDE: An End-to-end Embedded System Programming Platform". ALLI/O IDE is an end-to-end platform for programming embedded systems based on the ALLI/O Diagram, an action-based programming language for embedded systems published in VL/HCC 2024 (see [paper](https://nuntipat.me/assets/pdf/VLHCC_2024_ALLIO_final.pdf)).
