# Windshield Wipers (Visuino)

Download the diagram at [link](code/windshield_wiper.visuino) and follow the installation instruction for Visuino at [link](https://www.visuino.com/downloads/). Note that the diagram represents only the front wiper due to the program size limitation in the free version of the software. The diagram can be simply duplicated for the rear wiper due to the parallel execution of the Visuino program.
